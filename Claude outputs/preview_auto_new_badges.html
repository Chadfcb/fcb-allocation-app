How "New!" badges work now

Fixing the root cause, not just Operations' missed badge this one time.

Old way

Every time something new landed inside a section, I had to remember to also separately add that section's own button to a list. Miss that one step — like I did with Operations — and the button never lights up, even though New! badges show correctly one level deeper.

→

New way

A section's button now checks its own contents automatically — if anything unseen is nested inside it, anywhere, it lights up on its own. Nothing to remember, no separate step, can't be missed again.

What this means going forward

From now on, adding a brand-new page only ever needs that one page's own id added to the flagged list — same as always. Its parent, and its parent's parent, and so on up the tree, all light up automatically because they check what's inside them instead of needing their own separate flag. This applies everywhere in the sidebar (Operations, Sales, Calendars, Labels, UPC's, and every brand underneath Labels/UPC's), not just the one spot that broke.

Clicking a badge still only clears that one item, same as before — click Operations open and its own badge clears; the things still new inside it (Labels, UPC's, etc.) stay flagged until you click each of those too.
